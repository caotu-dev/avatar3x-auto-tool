# Avatar Fishing Bot v1.0.0

Bản phát hành đầu tiên cho Windows, giao diện tiếng Việt.

**Hiện tool chỉ hỗ trợ phần câu cá trong Avatar qua LDPlayer. Các hoạt động khác trong game sẽ được bổ sung trong tương lai.**

## Tải và sử dụng

1. Tải `AvatarFishingBot-windows-x64.zip` trong Assets bên dưới.
2. Giải nén toàn bộ thư mục, chạy `AvatarFishingBot.exe`. Không cần cài Python.
3. Mở LDPlayer, bật ADB và đặt độ phân giải 1600 × 900. Đăng nhập Avatar trước khi bắt đầu.
4. Chọn nhiệm vụ, xem lại Thiết lập rồi bấm Bắt đầu.

Giữ nguyên các thư viện cạnh file `.exe`. Bản portable không có bước cài đặt. ZIP không chứa cấu hình hoặc log cá nhân.

## Tính năng

- Câu tự do, mục tiêu tự đặt và đọc mục tiêu nhiệm vụ game.
- Hỗ trợ khu Sinh Thái và Bến Tàu; theo dõi cá, mồi, vé và nhật ký.
- Tùy chọn mua mồi/vé, bán cá và khôi phục phiên lỗi.
- Cải thiện chuyển tiếp giữa các lượt, cập nhật số dư và dọn log nền.

Bạn tự trả nhiệm vụ trong game. Các tùy chọn tự mua sử dụng Xu/Lượng trong game, hãy kiểm tra trước khi chạy.
