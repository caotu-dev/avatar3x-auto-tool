# Performance update — 2026-10-17

Measured on the existing emulator before changes: PNG capture ~0.72s, detection ~0.54s for one sampled live frame. Repeated capture benchmark: PNG mean 0.627s versus raw mean 0.450s (~28% lower). Raw capture supports Android 12/16-byte headers, validates size/format, converts RGBA to the same BGR pixels, and falls back permanently to PNG for unsupported raw payloads. GUI enables raw; existing explicitly supplied devices retain their selected backend. Timeout retries, Stop checkpoints and session-loss guarding remain.

Matching uses 384 response rows instead of 96, still below 3MiB per response and with existing single-thread OpenCV/tiny-anchor tie-breaking. Repeated same-fixture detection mean: 0.560s -> 0.366s (~35% lower). Fixed UI search regions in WorldDetector reduce center-map recognition on the same image from ~0.123s to ~0.041s. Thresholds are unchanged. Cached per-area fishing detectors avoid reconstructing map fallback assets. Login guard skips dark-button matching when its required logo is absent.

Session can hand off its two-frame verified READY observation directly to OneRoundBot only within 0.25s, preventing an extra redundant capture/detection before casting. Old readiness forces a fresh capture. GUI observation sleeps reduced to 30ms (session) and 20ms (round/navigation), while confirmation counts and loading/purchase protections remain unchanged. Fake-clock tests cover fresh/expired handoff and raw-decoding/fallback behavior. Memory test now enforces a 3MiB maximum response buffer rather than the previous 0.6MiB target.

Live trial: entered ca_ro, pressed a verified chair 1.129s after map confirmation, cast 3.106s after pressing the chair, solved the board and caught one Cá rô, COMPLETE. Total time included server bite wait. No purchases. One test bait and the caught fish recorded in durable inventory; applicable mission progress incremented. Existing game action was allowed to finish before the test; its map changed to center, so the final successful trial explicitly navigated from center. Detailed timings: performance-live-result.json. Full captures used for diagnosis are removed after validation to keep the repository small.
