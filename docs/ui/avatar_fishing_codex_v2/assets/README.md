# Avatar Fishing Mockup Assets

This package contains PNG assets cropped from the latest approved mockups:
- references/dashboard_main.png
- references/dashboard_settings_popup.png

## Folders
- banners/: header/banner crops
- controls/: top bar buttons, tabs, action controls
- cards/: larger content cards and status tiles
- fish-icons/: fish/crab icons extracted from the table
- popup/: settings modal and inner sections
- icons/: small header/section icons
- references/: full source mockups

## Notes
1. These are flattened PNG crops from mockups, not vector or layered design files.
2. Use them as visual references or temporary assets for implementation.
3. For production quality, consider redrawing some icons as SVG/vector.
4. Exact crop rectangles are listed in manifest.json.
